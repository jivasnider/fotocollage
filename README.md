# Photo Collage ❤️

An interactive photo collage built with HTML, CSS, and JavaScript. The project presents four photographs in an expandable panel layout, creating a simple and personal visual experience.

## Live Demo

**[View Photo Collage](https://jivasnider.github.io/fotocollage/)**

## Preview

The collage consists of four interactive photo panels displaying the message:

**Anna – I – Love – You**

Click on any panel to expand it and bring its photograph into focus.

## Features

- Interactive expandable photo panels
- Smooth CSS transitions and animations
- Custom typography using Google Fonts
- Personalized photo gallery layout
- Simple and lightweight implementation

## Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Layout, styling, and transitions
- **JavaScript** – Interactive panel selection
- **Google Fonts** – Dancing Script typography

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/jivasnider/fotocollage.git
```

2. Navigate to the project directory:

```bash
cd fotocollage
```

3. Open `index.html` in your web browser.

No additional dependencies or installations are required.
